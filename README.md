# Local Farms

I wanted to make a map with the local farms in the area so people could support local farmers.

## Instructions for Build and Use

## Steps to build and/or run the software

1. Download or clone the project files into a local folder.
2. Make sure the project contains the following files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `farms.json`
3. Open the project folder in Visual Studio Code or another code editor.
4. Install the Live Server extension in Visual Studio Code (recommended).
5. Right-click `index.html` and select **Open with Live Server**.
6. The application will open in your default web browser.

## Instructions for using the software

1. Open the website in your browser.
2. Use the category checkboxes to filter different types of farms.
3. Use the distance slider to adjust the search radius.
4. Click anywhere on the map to place a center point for distance filtering.
5. Click “Select All Farms” to enable all farm categories.
6. Click “Clear” to remove all category selections.
7. Click on any farm marker to view information about that farm.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

- Visual Studio Code
- Live Server Extension for Visual Studio Code
- Leaflet.js
- OpenStreetMap Tile Layer
- Modern web browser (Google Chrome, Microsoft Edge, or Firefox)
